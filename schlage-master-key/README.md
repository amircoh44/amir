# Schlage Master Key System Designer

A self-contained app for locksmiths that **designs a master key system** and
exports a **set of printable PDF cut / pinning sheets**. Built to drop into a
WordPress page — either as raw HTML in an **Elementor "HTML" widget**, or as a
proper plugin with a `[schlage_master_key]` shortcode.

It follows **Schlage-Classic** conventions (cut depths `0–9`, `.015"`
increments, bottom-pin number = cut depth, MACS 7) and uses **Total Position
Progression** with **two-step progression** so every master (build-up) pin is
even and at least `.030"` (2 increments) for reliable wafers.

---

## What it does

- **Top Master Key (TMK)** + a set of **change keys**, with an optional
  **Grand Master Key (GMK)** for a 3-level system.
- **Two-step progression** (even or odd) generated by odometer-style Total
  Position Progression across the chambers.
- **MACS validation** on every key (default 7, configurable).
- **Key-interchange / phantom-key detection** — during generation it *rejects*
  any candidate change key that would also open another cylinder, so no two
  delivered keys cross-open. It also reports how many incidental "phantom" keys
  each individual cylinder has.
- **Per-cylinder pin stacks** — bottom pin + master pins for every chamber.
- **PDF export** — a multi-page set of sheets:
  1. **System Summary** — all parameters and counts.
  2. **Key Schedule** — every key stamp, bitting, and assignment.
  3. **Master Pinning Chart** — the full pinning matrix.
  4. **Door Pinning Tickets** — one ticket per cylinder for the bench.

## Three ways to use it

### 1. Elementor "HTML" widget (no plugin) — easiest
Open [`schlage-master-key.html`](schlage-master-key.html), copy the **entire
file contents**, and paste it into an Elementor **HTML** widget (or a Gutenberg
"Custom HTML" block). It is fully self-contained — styles and logic are inlined;
the only externals are the jsPDF + jsPDF-AutoTable CDN scripts, which the markup
loads itself. The page must be able to reach `cdnjs.cloudflare.com`.

### 2. WordPress plugin (PHP shortcode)
1. Zip this `schlage-master-key/` folder.
2. WordPress admin → **Plugins → Add New → Upload Plugin** → upload → **Activate**.
3. Put the shortcode anywhere — a page, a Gutenberg **Shortcode** block, or an
   Elementor **Shortcode** widget:
   ```
   [schlage_master_key]
   ```
The plugin ([`schlage-master-key.php`](schlage-master-key.php)) registers the
shortcode and enqueues the CSS/JS in `app/` plus the jsPDF CDN scripts only on
pages that use it.

### 3. Standalone
Just open `schlage-master-key.html` in any modern browser.

## The keying math (so you can trust the sheets)

For each chamber of a cylinder, collect the cut depths of **all** keys that must
operate it (TMK, GMK if any, and the change key), sorted ascending
`d0 < d1 < … < dn`:

- **Bottom pin** = `d0` (the shallowest cut).
- **Master pins** = the differences between adjacent depths: `d1−d0, d2−d1, …`.
- The stack therefore sums to the deepest cut, so a shear line forms for every
  operating key. Two-step progression guarantees each difference is even and
  `≥ 2`.

Pin numbers are in `.015"` increments (`B6` = a #6 bottom pin; `M4` = a #4
master pin), matching how Schlage pin kits are numbered.

> **Always bench-verify the first cylinder before pinning a full system.** This
> tool is for authorized locksmithing work.

## Tech notes

- No build step or framework. Plain ES5-compatible JavaScript, self-mounting
  into `#smk-app`.
- PDF generation is 100% client-side via
  [jsPDF](https://github.com/parallax/jsPDF) `2.5.1` +
  [jsPDF-AutoTable](https://github.com/simonbengtsson/jsPDF-AutoTable) `3.8.2`.
- The engine is unit-tested for pin-stack correctness, two-step master pins,
  MACS, and zero key interchange among delivered keys.
